# Design system — do not deviate

The design system in [design.md](design.md) is binding. Before any UI, component, layout, CSS,
or `globals.css` change, read design.md and stay strictly within its tokens, classes, component
skeletons, and behavior contracts. Do not invent new visual patterns; if a new pattern is truly
needed, add it to design.md first, then implement.
